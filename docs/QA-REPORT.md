## 3. 源码 Bug 清单（路由 → Engineer，QA 未改源码）

### B1【中】搜索接口 FTS5 语法注入 → HTTP 500
- **位置**：`app/api/routes_search.py:25-43`（`build_match_terms`），抛点 `app/index/database.py:355`
- **复现**：`GET /api/search?q=a**b` ／ `q=会议"查询` ／ `q=\AND` → 500 `sqlite3.OperationalError: fts5: syntax error`
- **根因**：① ASCII 词内部 `*` 未消毒拼出非法 bareword；② CJK 词含 `"` 破坏引号短语；③ 清洗后残留 FTS5 关键字（AND/OR/NOT/NEAR）作 bareword 前缀
- **失败测试**：`test_qa_supplement.py::TestSearchRobustness::test_special_chars_no_500[a**b / 会议"查询 / \AND]`
- **修复建议**：构造 MATCH 前过滤 `"` 与词中 `*`（仅允许尾部一个）、转义保留字；或兜底捕获 `sqlite3.OperationalError` 返回 400

### B2【中】可向隐藏目录写入笔记
- **位置**：`app/paths.py:53-69`（`validate_relative` 未拒绝 `IGNORED_DIRS`）
- **复现**：`POST /api/note {"path": ".kwey/隐藏笔记.md"}` → 200，文件实际落入 `.kwey/`（`.trash/`、`.git/` 同理）
- **失败测试**：`TestPathSecurity::test_write_into_hidden_dir`
- **修复建议**：`validate_relative` 对任一路径片段命中 `IGNORED_DIRS` 抛 PathError（注意放行 VaultService 内部对 `.trash` 的合法移动）

### B3【低】delete_dir 不清理目录下附件的链接图登记
- **位置**：`app/vault/service.py:313-334`（`delete_dir` 仅遍历 `notes` 表）
- **复现**：目录含附件 → `DELETE /api/files/dir?confirm=1` → `linkgraph.resolve("图.png")` 仍返回已删路径，后续 `![[图.png]]` 嵌入解析到不存在文件
- **失败测试**：`TestAttachmentSettings::test_delete_dir_cleans_graph`

### B4【低/观察】笔记自嵌入出现在自身反链面板
- **位置**：`app/api/routes_graph.py:28-47`（backlinks 未排除 self；自引用 `![[欢迎]]` 使 `欢迎.md` 列在自己的反链里，Obsidian 惯例排除自链）
- **说明**：PRD 未明确规定，交产品/工程师裁决是否排除

### B5【低/观察】自写落盘产生多余 `.kwey-tmp` WS 事件
- **位置**：`app/vault/service.py:125-129` + `app/vault/watcher.py:81-87`
- **现象**：冒烟实测 WS 收到 `created`/`deleted`（path=`xxx.md.kwey-tmp`）杂音事件；建议 `watch_filter` 排除 `*.kwey-tmp`

### 工程师自报遗留项复核
- a) FTS snippet CJK 紧邻半角标点残留空格：**属实**（`cjk_compact` 仅消除 CJK-CJK 间空格），显示层副作用，接受为已知限制
- b) watcher `watch()` 元组 set 双形式兼容：**实现正确**，QA 已补真实元组形态测试背书（`TestWatcherTupleForm`）
