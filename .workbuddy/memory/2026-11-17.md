### 修复：内置智能体聊天 401
- 根因：`chat.js` 用原生 `fetch('/api/agent/chat')` 未带 `X-Kwey-Token`（A4 后该端点需 write 级 token），而 `api.js` 只覆盖 `api.*` 请求。
- 修复：`api.js` 导出 `authHeaders()`；`chat.js` 注入 token，并在 401 时 `renewToken()` 重放一次。

- 验证：无 token 请求 401、带 token 200；浏览器实测「你好」得到回复；协议 http↔openai 切换即时禁用/启用发送。
