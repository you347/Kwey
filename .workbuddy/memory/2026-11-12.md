## Kwey 产品设计定稿（第一轮）
- 定位：本地优先、Markdown 文件为唯一事实源、Agent 原生的个人知识库（对标 Obsidian）。
- 三重身份：独立知识库 / 外部 Agent 的知识源与工作区 / 内嵌 Agent 整理工作台。
- 双向连接方案：
  - 外部 Agent → Kwey：MCP Server（tools：search/read/write/create/link/tags/graph）+ 本地 token 权限分级。
  - Kwey → 外部 Agent：文件 watcher 事件总线（SSE/WS 推送变更）+ Agent Provider 适配器（HTTP/OpenAI 兼容，指向用户自建 agent 系统）。
- 关键架构决定：
  - 磁盘 Markdown 为事实源，SQLite（FTS5 + 向量）仅做索引、可随时重建。
  - 所有写入统一走 Vault Service（锁 + 防抖重索引 + 事件广播）。
  - agent 返回结构化 ops（create/append/tag/link），UI diff 确认后落盘，写入前快照可回滚。
- 分层：UI 层 / Agent Link 层 / 核心域层 / Agent Provider 适配器；MCP server 建议做成 sidecar 独立进程。
- 待定：技术栈（Electron+TS 推荐；备选 Java Spring Boot 核心 + Web UI）、向量库选型（sqlite-vec 起步）。
